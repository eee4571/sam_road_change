## 用户指出东北侧主轴漏提后的补充实验

目视放大及横断面支持用户的观察：西北—东南向宽路两侧有轴线，中间缺少主轴。检查的一对轴线相距约 35m，明显超出普通 duplicate 规则的最大 12m 搜索范围。
中间路面有持续、均匀的 RGB 支持，但 SAM probability 几乎为零；简单删除一侧轴线、或把强 SAM 支持设为恢复主轴的必要条件，都不能解决这个问题。

已增加 `ribbon_diagnostic.py` 的独立 RGB 中央轴候选诊断。
最终补充运行目录为 `outputs/20260928T100724Z_07cc7ae2/`，耗时约 26.2s，输入指纹不变。
三类修正实验与前述主实验结果相同，额外识别 8 段候选内部轴线，合计约 232.34m；对应两侧轴线间距约 29.5～34.9m。
候选的 SAM 平均概率约 0～0.012，说明本例不能依赖高 SAM 概率才进入审查。
