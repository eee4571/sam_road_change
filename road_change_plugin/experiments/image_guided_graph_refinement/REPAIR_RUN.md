## 算法与代码

- `run_repair.py`：独立 CLI、ROI/整期分块、迭代、退化撤回与来源审计；正式 CLI/pipeline 接口不变。
- `medial_repair.py`：复用既有 boundary-axis 诊断，从 RGB 道路带拟合中央轴；替换旧侧轴、重建路口、保留并重挂外部接触点。
- `rgb_route.py`：统一 RGB ribbon 代价特征；端点方向在路径搜索转移中生效；SAM/MOLRA 只提供正证据，surface 不参与独立道路判定。
- `local_graph_repair.py`：相邻伪环区域一起处理，避免收缩成重复小支路；复用正式 `_pinned_smooth`，固定节点做有界平滑。
- `repair_artifacts.py`：完整期次矢量、分层几何差、图、统计和报告。
- `evidence.py`：只缓存有效像元浮点数组，避免每次采样重复复制整幅 ROI；第一轮判定逻辑未改。
- `test_repair.py`、`README.md`、`.gitignore`：回归测试、运行说明与成果忽略规则。

继承正式测宽属性仅用于辅助尺度，不重新测宽，也不将这些属性声称为修复后重新测得的宽度。
真实平行道路保护要求两侧各自有独立 RGB ribbon，且中间有持续分隔带；新增回归覆盖了“暗色中央分隔带被误当道路”的反例。
