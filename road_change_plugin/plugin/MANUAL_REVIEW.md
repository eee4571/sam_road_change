# 变化成果人工复核

处理完成后，在主页“成果”中点击 **人工复核变化**。

## 人工判读

- 左侧按复核状态筛选候选，右侧对照前后期影像。黄色轮廓标示当前候选，滚轮缩放、拖动平移，两期同步。空格显示或隐藏轮廓，近景/中景/远景调整范围，“居中”恢复候选完整视图。
- 影像下方点击 **有真实变化 · 保留（1）** 或 **无真实变化 · 剔除（2）**。每次判断立即自动保存到磁盘，保存成功后自动进入下一条待复核候选。
- 本组完成后自动进入本区域下一组未完成期次；本区域全部完成后进入下一区域。已完成或没有变化的组会跳过。
- **撤销（Ctrl+Z）** 恢复上一次判断，并自动保存，支持跨期次和区域返回。更多菜单提供“暂时跳过（3）”“设为待复核”、正式成果文件和操作说明。
- 自动保存失败时停止跳转，显示“重试保存判断”。关闭时会警告最近一次修改尚未保存，提供重试保存并退出、不保存退出、继续复核。正在写入最后一次判断时，等待保存成功后关闭。

## 复核汇总

点击 **复核汇总**，按区域和期次查看待复核、已保留、已剔除数量及待应用状态。选择某组可返回修改；本组已完成时突出汇总入口，点击候选或“修改当前判断”可重新判断。

关闭并重新进入会恢复已自动保存的判断。此时正式成果仍保持上次应用的版本，不会因关闭窗口而自动执行耗时更新。

## 应用成果

点击 **应用复核结果（Ctrl+S）**，统一更新所有已修改组，包括上次关闭前保存、这次尚未打开的组。应用操作才会：

- 只将人工判定为“保留”的候选写入正式变化；待复核项保留在本工具中，剔除项也可重新判断。
- 更新对应区域的长时序变化、统计、成果清单和任务报告。
- 有真值数据时重新计算精度，保留其他变化对的评价；无真值时标记未评价。

成功后显示明确反馈并刷新主页成果和指标。单期道路几何和观测不变；已有长时序匹配和测宽记录复用，不重新提取道路。全部剔除时仍生成包含坐标系和属性结构的空 SHP。

应用过程中关闭会警告，默认 **继续等待**，也可 **仍然退出**。判断记录已经保存；如果退出中断成果发布，再次进入复核时会恢复该组上次完整成果，可重新应用。批量应用中先完成的组保持有效，尚未完成的组继续显示待应用。

## 存储与恢复

自动检测的高、低置信度候选统一在本工具复核，置信度仅用于排序，不自动批准。
新检测的候选保存在后端变化目录的 `review_candidates.shp`，正式变化在人工应用前为空。
已有项目的正式变化仍可通过同一工具复核。判断自动保存不发布成果，应用时才更新正式结果。

每个变化对在原变化 SHP 同目录的 `人工复核/<原文件名>/` 下保存：

- `draft.json`：逐条自动保存的判断，原子替换写入，仅记录判断，不更新正式成果。
- `current.json`：最近完整应用版本的指针。
- `original_changes.shp`：原始检测结果备份，可恢复此前剔除的候选。
- 版本目录：`road_changes_reviewed.shp`、`false_changes.shp` 和 `review.json`，分别保存复核成果、剔除要素和已应用判断。

复核记录绑定原始数据及处理输入。检测结果改变时不套用旧记录；应用前再次校验数据。派生成果全部生成成功后统一发布，失败恢复上一完整成果，但保留最新判断记录。多个窗口不能同时处理或复核同一项目。完整重算或局部重跑可能清理所在成果目录，需长期保留的备份应另行复制。

影像支持单影像、TXT 清单和目录，只读取当前候选附近的窗口，前后期使用同一范围和显示拉伸。缺少影像或坐标系会明确提示。宿主只依赖 PySide6，GIS 在独立后台执行，不加载模型。公共 Plugin API 和成果信号不变。
