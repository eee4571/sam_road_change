# 插件 UI 产品约束

后续修改本目录及 `../widget.py` 时遵守以下产品约束：

- 用户入口只运行正式 Fast 流程；不提供模式选择，不展示 full / fast 内部标识。
- 真值辅助机制属于内部实现，不提供相关开关、参数或机制说明。
- 用户文案使用“真值数据”，不使用 GT、GT-assisted、GT校正、GT辅助。
- 有可用真值时自动评价（允许部分变化对有真值），无真值时跳过；不提供评价开关或手动评价入口。
- 高级设置只呈现用户可理解的业务参数；不暴露设备实现、缓存、算法分支或 finalization。
- 业务表达保持：数据 → 道路变化检测 → 成果 → 可用时显示精度评价。
- 历史成果可以查看；仅支持正式 Fast 任务续跑和局部重跑，不通过改写旧 manifest 转换历史任务。
- 保持 Plugin API、Signals、result_type、独立进程边界；UI 测试不得运行真实模型。
