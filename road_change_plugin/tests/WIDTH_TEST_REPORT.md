## 验收边界与剩余风险

- 实际插件使用 `fast + raw_image`；历史 full 模式仅验证共享采样/链回退等函数，未做全流程验收。
- 未运行完整模型推理、长时序项目或所有区域精度基准。正常剖面的数值回归和一个真实项目子集不能代替这些验证。
- 混合可信/低可信观测的整链代表值保守标为 C，可能降低低证据区域的自动宽变召回；对应明细仍可人工复核。
- 超过单道路 20000 个断面的计算预算会使用带原因的低可信估计，避免异常长线无界分配。
- 缺失 CRS、不兼容影像网格/波段、不可写输出和系统内存失败继续返回失败，需修复输入或环境后续跑。
- 本机没有故障电脑的数据和 traceback，不能确认那次异常唯一根因或声称远端环境已验收。

运行、缓存、默认宽度及诊断路径见 [WIDTH_RESILIENCE.md](WIDTH_RESILIENCE.md)。
进一步定位需故障电脑完整日志、`period_state.json`、`input_manifest.json`、代码版本，以及必要时失败切片的中心线/掩膜/影像元数据。
