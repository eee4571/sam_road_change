# 判为假变化的辅助对象退出评价

用户明确要求：人工复核将某个真值辅助对象判为假变化后，其对应真值不再参与评价。原实现仅支持完整源真值对象的整体拒绝，导致局部拒绝仍算漏检。本次修正不改变查全率公式。

## 规则

- 根据审计中的来源 ID、变化类别和实际空间交集定位被否定的辅助范围；没有来源关联的自动检测对象，不据此剔除真值。
- 完整源对象整体被否定时整体退出；部分补入、截短或源对象中只有部分被否定时，仅扣除对应空间范围。
- 空间对应采用正式评价相同的影像网格及 4 px 容差；仍保留同一源对象中其他保留、待复核、未映射和未展示部分。不会因为道路相邻就删除另一个源对象。
- 原始真值文件不变。新复核记录保存整对象/局部范围及关联来源；评价真值在内存中重新生成，撤销拒绝会恢复对应范围。
- 保存复核和单独重评共用同一实现。重评读取旧项目已保存的原始候选备份和复核决定，旧的空过滤结果不会阻止局部修正规则生效。旧的整对象过滤记录仍可读取。
- GUI、CLI 和插件 API 不变；复核记录只增加局部范围字段。

## 真实数据复测

复用此前 6 个变化对、4 px 容差的缓存。每种情况为独立模拟，其他变化对全部保留候选。重新评价已保存的复核记录，使用正式汇总函数计算项目指标：

| 模拟复核 | 修正前项目查全率 | 修正后项目查全率 | 修正后对应变化对查全率 |
| --- | ---: | ---: | ---: |
| 删除一个较小完整对象 | 94.9777% | 94.9777% | 94.4605% |
| 删除三个完整对象 | 94.7643% | 94.7643% | 93.0903% |
| 删除一个较小局部候选 | 94.9862% | 94.9992% | 94.9955% |
| 删除一个较大局部候选 | 76.3306% | 93.8522% | 91.4636% |

上述四份已保存复核成果分别有 176 个被核验的源文件，内容和修改时间未变。对较大局部候选另行执行真实保存复核、长时序更新、评价和发布，结果一致，217 个上游缓存文件保持不变。未运行道路提取、测宽或变化检测。

被否定范围退出真值后，评价分母会变小，未被否定的漏检仍需计算。因此指标如实变化，不承诺所有变化对都保持在预设区间。

上述测试分别为 13、13、16、12、10、16 项，共 80 项通过；语法检查和 `git diff --check` 通过。

既有复核测试夹具同时补齐影像网格和当前容差指标字段，避免混用旧面积指标与新容差指标。
