## 实测发现与修复

- 复制工程的状态和 manifest 仍引用原工程，提交被“成果目录属于其他项目，不能覆盖”拦截。现在打开工程时由 Controller 调用标准库路径迁移子进程，修正项目内 JSON 和工作目录内路径清单，再扫描界面。
- 深层测宽缓存追加备份及临时文件名后超过 Windows 普通路径长度限制。备份和原子写入使用扩展路径进行 I/O，manifest 仍保存正常路径。
- 大量缓存记录使首次迁移耗时较长。按目录去重校验、复用路径映射缓存、有界并发读取小文件；映射和写入保持顺序。修改前备份，配置最后提交，中断后可重试。
- 正式导出将折返道路质量提示中的几何指纹错误地当作数组下标，抛出 `TypeError`。现在仅转换轴线修复记录的下标，保留质量提示指纹及道路；不修改正式几何版本或触发模型计算。
- 桌面把期次元数据的字段数当成期次数，并忽略未复制到发布目录的内部测宽文件，错误显示“已有 2/4”“已有 1/3”“测宽未运行”。现在读取实际期次和变化对计划，逐项查找成果路径；缺失成果仍显示失效。

保持既有 Plugin API、后端流水线 CLI 和 manifest 格式。
