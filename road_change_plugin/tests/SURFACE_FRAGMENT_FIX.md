# 变化候选几何碎片修复（2026-10-13）

## 原因与修复

截图中的 CH000002 是约 1.057 平方米的独立三角形。对原缓存重放可追溯到一条约 425 米的合并轴线：旧变宽度道路面把两侧偏移边界拼成一个环，在短弯处发生自交，`make_valid` 将自交部分拆成小岛。候选导出随后将每个独立面编号为一条待复核记录。

`auto_change_geometry.corridor` 改为逐段生成变宽度梯形、在转弯外侧生成圆弧扇形，再合并成连续道路面。每个构件连接其来源轴线或转弯节点，不再依靠修复自交环生成道路面。合并采用微米级坐标精度，消除 UTM 大坐标下圆弧端点浮点误差造成的假分离。轴线、纵向区间、宽度观测、平端点及正常环路内部空地保持其原有含义。

没有增加面积阈值、置信度过滤或新复核流程。真实独立小道路和不穿过中心线的宽度变化侧边条带仍会导出。正式成果仍需人工确认。CLI、成果字段和 GUI 接口不变。
